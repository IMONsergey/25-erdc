# 25 ERDC — Новый облик городов Дальнего Востока

Адаптивный React-сайт мастер-планов Дальнего Востока. Главная воссоздана по исходному порталу, региональные страницы — по Figma Page 12 в общей синей визуальной системе.

## Страницы

- `/` — главная; `/regions/` — выбор всех 11 регионов.
- `/primorye/`, `/buryatia/`, `/khabkrai/`, `/kamchatka/`, `/yakutia/`, `/chukot/`, `/zabaikal/`, `/amurskaya/`, `/sakhalin/`, `/eao/`, `/magadan/` — региональные страницы.
- `/vladivostok/` — утверждённая агломерация Владивостока с 27 проектами; исходные блоки защищены проверкой сборки.
- `/cities/<id>/` — 22 других раздела городов и агломераций в той же визуальной системе.
- `/projects/`, `/news/`, `/dvkvartal/`, `/map/` — проекты, новости, жилищная программа и карта.
- `/qa/` — проверка страниц в размерах телефона, планшета и монитора.

Все адреса работают и в подпапке `/25-erdc/` на GitHub Pages.
Подробности текущего прохода — `docs/approved-territories-20260923.md`.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-сборка: `npm run build`. GitHub Pages автоматически собирает и публикует `dist/`.

## Структура

- `src/components/` — независимые блоки и интерактивы страницы;
- `src/data.js` — контент городов, категорий и проектов;
- `src/styles.css` — дизайн-система и desktop/tablet/mobile адаптив;
- `scripts/fetch-assets.sh` — однократное сохранение исходных Figma-ассетов;
- `.github/workflows/pages.yml` — автоматический деплой на GitHub Pages.
