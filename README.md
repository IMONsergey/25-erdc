# 25 ERDC — Новый облик городов Дальнего Востока

Адаптивный React-сайт мастер-планов Дальнего Востока. Главная воссоздана по исходному порталу, все 11 региональных страниц используют структуру и оформление утверждённой Владивостокской агломерации от 22 сентября, 15:00 МСК.

## Страницы

- `/` — главная; `/regions/` — выбор всех 11 регионов.
- `/primorye/`, `/buryatia/`, `/khabkrai/`, `/kamchatka/`, `/yakutia/`, `/chukot/`, `/zabaikal/`, `/amurskaya/`, `/sakhalin/`, `/eao/`, `/magadan/` — региональные страницы.
- `/vladivostok/` — утверждённая агломерация Владивостока с 27 проектами; исходные блоки защищены проверкой сборки.
- `/cities/<id>/` — 22 других раздела городов и агломераций в той же визуальной системе.
- `/projects/`, `/news/`, `/dvkvartal/`, `/map/` — проекты, новости, жилищная программа и карта.
- `/qa/` — проверка страниц в размерах телефона, планшета и монитора.

Все адреса работают и в подпапке `/25-erdc/` на GitHub Pages.
ДВ кварталы представлены на одной странице; новости открываются в модальном окне.
Подробности текущего прохода — `docs/site-interactions-20260923.md`.
Основная страница Владивостокской агломерации — `/vladivostok/`, без параметров восстановления. `/cities/vladivostok/` и старые ссылки перенаправляются на неё.

Текущий региональный шаблон — `docs/regional-template-20260923.md`. Не заменять каноническую агломерацию региональной страницей `/primorye/`.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-сборка: `npm run build`. GitHub Pages автоматически собирает и публикует `dist/`.

## Структура

- `src/vladivostok-20260922/` — изолированная утверждённая агломерация, 17 исходных файлов и 78 ассетов защищены `docs/vladivostok-20260922-1500.json`;
- `src/pages/TerritoryPage.jsx` и `RegionalAtlas.jsx` — общий шаблон регионов;
- `src/components/` — общие блоки и интерактивы;
- `src/data.js` — контент городов, категорий и проектов;
- `src/styles.css` — дизайн-система и desktop/tablet/mobile адаптив;
- `scripts/fetch-assets.sh` — однократное сохранение исходных Figma-ассетов;
- `.github/workflows/pages.yml` — автоматический деплой на GitHub Pages.
