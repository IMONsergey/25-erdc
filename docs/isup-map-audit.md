# Аудит карты ИСУП

Дата проверки: 18 августа 2026. Проверка выполнена через локальный Chromium с demo-доступом. Облачный браузер не использовался для вывода о доступности, потому что ранее он блокировался WAF.

## Что удалось открыть

`https://isup.erdc.ru/map/map` открывается и редиректит на `https://isup.erdc.ru/map/`. Заголовок страницы: `Публичная карта`. Основной экран показывает карту мастер-планов ДФО и Арктики, левую панель со списком городов, верхний поиск, кнопку фильтров, zoom-контролы, кнопку геолокации и легенду стадий.

## Пользовательский сценарий

1. Пользователь открывает карту и видит список 22 мастер-планов с количеством объектов.
2. При выборе `Владивостокская городская агломерация` карта переходит к Владивостоку и показывает 277 объектов.
3. Левая панель меняется на карточку мастер-плана: donut по стадиям, подборки по отраслям, последние обновления.
4. Поиск `школа` записывается в URL как `searchQuery` и ограничивает выдачу через WFS search view.
5. Кнопка `Фильтры` открывает панель со стадиями, отраслями, мастер-планами и кнопкой применения.
6. На дальнем масштабе точки группируются в кластеры с числами, на близком масштабе становятся отдельными отраслевыми маркерами.

## Структура интерфейса

- Верхняя панель: логотип `Мастер-планы`, поиск объектов, фильтр.
- Левая панель desktop: стек glass-панелей шириной около 480 px.
- Карточка мастер-плана: заголовок, счётчик объектов, стадии, подборки, последние обновления.
- Фильтры: отдельная левая sheet-панель вместо основной панели.
- Карта: canvas OpenLayers, WMS-подложка, кластеры, одиночные маркеры.
- Легенда: нижняя плавающая строка стадий.
- Mobile: верхняя панель сохраняется, левая панель становится нижней sheet-панелью.

## Карта состояний

- `loading`: skeleton-элементы в списках и карточках.
- `master plans`: список городов/мастер-планов.
- `city selected`: карточка выбранного мастер-плана и объекты на карте.
- `filters open`: стадии pills, отрасли и мастер-планы checkbox-сеткой.
- `search`: query сохраняется в URL и используется в WFS `viewparams`.
- `clustered`: круговые маркеры с числами.
- `single marker`: отраслевые иконки на близком масштабе.
- `empty`: в CSS/DOM найдено состояние `city-empty` с подсказкой и reset-действием.

## Найденные технологии

- Framework: Vue 3, Vue Router.
- UI: Element Plus используется для части контролов и scrollbar/drawer/dialog.
- Карта: OpenLayers, DOM содержит `ol-viewport`, карта рендерится в `canvas`.
- Координаты: Web Mercator `EPSG:3857` для карты и WMS/WFS-запросов; GeoServer также поддерживает `EPSG:4326`.
- Тайлы: GeoServer WMS `https://geo-server.erdc.ru/geoserver/erdc/wms`, слой `erdc:azrf_dfo.osm.wms`.
- Геоданные: GeoServer WFS `GetFeature`, `outputFormat=application/json`, GeoJSON FeatureCollection.
- Кластеры: клиентская OpenLayers-кластеризация с иконками `showcase-object-cluster-*`.
- Состояние фильтров: URL query (`lng`, `lat`, `zoom`, `searchQuery`, `cityId`) плюс клиентское состояние.
- WebSocket/polling: в наблюдаемом сценарии не найдено.

## UX-проблемы

- На desktop прозрачная панель хорошо выглядит, но длинные заголовки и адреса агрессивно обрезаются.
- В фильтрах кнопка `Применить` визуально disabled до выбора, но выбранные checkbox-состояния не всегда очевидны без внимательного просмотра.
- На большом масштабе часть кластера и одиночных маркеров визуально конкурируют с нижней легендой.
- Кнопка геолокации есть, но её отказ/ошибка браузера не была явно показана в интерфейсе.

## Адаптивность

Mobile-вид работает как bottom sheet. На 390 px верхний поиск занимает почти всю ширину; нижняя панель перекрывает примерно половину карты и требует вертикального скролла. Это ожидаемо для плотной карты, но карточки объектов надо проектировать как отдельный bottom sheet, а не как desktop-side card.

## Доступность

Проверены основные focus-состояния через клавиатуру. У кнопок zoom есть текстовые accessible names (`Увеличить`, `Уменьшить`, `Моё местоположение`). Часть интерактивных карточек в sidebar выглядит как `div`/custom control, поэтому для копии на нашем сайте нужно делать их настоящими `button` с `aria-pressed`.

## Производительность

Страница подгружает крупные Vue/OpenLayers bundles и WMS-тайлы 256x256. Для выбранной агломерации WFS-запрос на точки и агрегаты отрабатывает без заметной задержки. Для нашего сайта OpenLayers вынесен в отдельный `/map-lab/` entry, чтобы не увеличивать основной bundle главной страницы.

## Ограничения аудита

Backend source code не изучался. Выводы относятся к наблюдаемому клиентскому API-контракту, DOM, network и production bundles. Изменяющие операции, формы создания/редактирования и административные сценарии не проверялись.

## Что нельзя было проверить

- Полный backend lifecycle авторизации и срок жизни сессии.
- Закрытые административные API.
- Серверную схему БД.
- Все возможные ошибки GeoServer и API под нагрузкой.
- Корректность каждого из 1753 объектов как бизнес-данных.
