## Сохранность и данные

- `check-region-lock.mjs` сравнивает HTML 11 регионов и каталога регионов, а также семь файлов утверждённого оформления с зафиксированной версией. Это обязательная часть сборки.
- Историческая страница Владивостока от 22 сентября, 15:00 МСК: проверки 17 файлов, 78 изображений, точки входа и 27 маркеров пройдены.
- Каталог не переписывался: 507 проектов, исходные показатели и изображения сохранены. В 22 городских атласах представлены все 335 записей их действующих мастер-планов. Владивосток использует свой утверждённый набор.
- Кнопки направлений на иллюстрациях — навигация по проектам, а не выдуманные точные географические координаты. Географические точки остаются в общей карте и исходном наборе данных.
- Группировка городских проектов — редакционная навигация по названиям. Неоднозначные названия остаются в «Развитии города».
- Фильтр новостей использует явные упоминания в заголовке и анонсе; он не приписывает регион национальной публикации по умолчанию.

## Проверки реализации

- Production build: 782 статических адреса, 598 канонических страниц; все проверки прошли.
- Каталог: регион → город → список, сохранение после перезагрузки, пустая выдача и очистка.
- Атласы: выбор направления и проекта, галерея, полный экран, прямой URL проекта, следующий проект, мобильная карточка 320 × 740.
- Главная → карта Хабаровска; общая карта → тот же мастер-план.
- Новости: подборка Магадана, переход между статьями в модальном окне, восстановление фильтра, закрытие Escape на телефоне.
- ДВ-кварталы: выбор сравниваемых объектов, исходные показатели, быстрый переход на телефоне.
- «О проекте»: вкладки с мышью и стрелками клавиатуры.
- Неиспользуемый полный набор Lucide исключён из сборки: отдельный адаптер иконок 2,63 kB вместо прежнего модуля 448,82 kB; нужные пиктограммы сохранены.
