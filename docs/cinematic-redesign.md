## Иллюстрированная карта

`assets/atlas-vladivostok.webp` — художественная генерация, выполненная встроенным ImageGen по исходной береговой линии `assets/projects-map.webp`. Это композиционная схема, не кадастровая и не навигационная карта. Подпись об условном расположении постоянно видна.

Ключевой запрос генерации: кинематографическая объёмная модель Владивостока и острова Русский, высокий ракурс, подробный зелёный рельеф и городская застройка, глубокое синее море, бирюзовая береговая линия, свободное море слева для интерфейса, без текста, точек, оранжевых зон и встроенного интерфейса.

`anchor` — проценты внутри изображения, а не географические координаты. Камера и маркеры находятся в одной системе координат и масштабируются вместе. Максимум четыре маркера одновременно (рекреация и экология), а не 27 точек поверх всей сцены. Все 27 записей доступны через семь направлений.

Выбор проекта управляет приближением сцены, активным маркером или областью и карточкой. Есть следующий/предыдущий проект, сброс общего вида, полноэкранный режим, закрытие Escape, клавиатурный фокус и reduced-motion. На мобильных карта остаётся сверху, список и карточка становятся вертикальным интерфейсом. Навигация по разделам не перехватывает обычную прокрутку.

## Сборка и совместимость

`npm ci` → `npm run build`. Публикация работает через существующий GitHub Pages workflow.

Главная страница не загружает OpenLayers или внешний картографический API. Экспериментальная `/map-lab/` сохранена отдельно, со своей копией прежнего CSS (`src/map-lab/legacy-styles.css`). Её большой bundle не попадает в загрузку главной страницы.

Имена и порядок всех 27 записей сверены с Excel. Production-сборка проходит.
